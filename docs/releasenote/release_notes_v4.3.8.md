## LeanType 4.3.8

### Fixed
- **Words auto-corrected to emojis (#932)**: In 4.3.7, typing a keyword from an emoji dictionary could replace the word with an emoji, even when it was a valid word. With Auto-correct shortcuts on, only your personal dictionary shortcuts now override valid words.
- **No emoji auto-correct (#931)**: Auto-correct no longer replaces a typed word with an emoji, for example in a language that has an emoji dictionary but no word list. Shortcuts you map to an emoji in your personal dictionary still apply.
