## LeanType 4.3.9

### Added
- **Japanese 12-key kana layout (#936, #938)**: A four-row kana grid where long-press gives the rest of each kana row, including voiced and small kana. Split mode and gesture typing are off on this grid. Kanji suggestions need CJK plugin v1.0.3 or later.

### Fixed
- **Suggestions after backspace in browsers (#937)**: After a space and a backspace in a web text field, tapping a suggestion could add it to the end of the word. The keyboard now picks the word up again.

### Maintenance
- **Docs and tests (#939)**: Corrected feature claims and settings paths in the README and feature guide, and updated an outdated layout test.
