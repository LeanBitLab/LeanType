## LeanType 4.3.7

### Added
- **Remove downloaded translations (#927)**: Storage and cache now lists the app translations you downloaded and lets you remove them to free space.

### Fixed
- **All caps suggestions (#914)**: Suggestions no longer offer an all caps variant of a word when the lowercase word is more likely.
- **English fallback words**: Languages without a word list no longer show English fallback words as suggestions.
