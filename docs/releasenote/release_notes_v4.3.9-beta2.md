## LeanType 4.3.9

### Fixed
- **Split keyboard settings on tablets (#940)**: On large screens without a hinge, the Enable split keyboard switches (portrait and landscape) and Split distance now work, and the duplicate unfolded split settings are hidden. Defaults are unchanged, so tablets still start split.
- **Split settings on foldables and phones (#940)**: The toolbar split key on an unfolded foldable no longer changes the folded screen, and Split keyboard when unfolded applies to both orientations again. On phones, a value saved with the toolbar key no longer overrides the landscape split switch.

### Maintenance
- **Tests and testing status (#940)**: Added unit tests for the split settings. The fix has not been tested on a tablet or foldable device, so beta testers with either are asked to verify it.
