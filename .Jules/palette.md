## 2024-05-14 - Standardizing Dialog Close Touch Targets and Feedback
**Learning:** Purely decorative image views functioning as action buttons (e.g. "Close" icons) frequently miss vital visual interaction cues (like ripple effects) and semantic localized content descriptions (often relying on ad-hoc or null descriptions). Using `android:padding` on an ImageView acts as an effective way to increase touch targets and provide space for a ripple effect `?android:attr/selectableItemBackgroundBorderless`.
**Action:** When inspecting micro-interactions in Android XML layouts, systematically check `ImageView` elements used as interactive components. Ensure they implement `android:background="?android:attr/selectableItemBackgroundBorderless"`, have adequate `android:padding` (e.g. `8dp`) for hit area and visual spacing, and use standardized string resources like `@string/dialog_close` for `android:contentDescription`.
